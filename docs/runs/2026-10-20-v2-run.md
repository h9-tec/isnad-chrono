## Odd or worth a look before the push

1. Shawahid companions are all unresolved at the groups stage because the site gives
   `narrator: null`. The README's description of `shawahid` ("by other Companions, ids only") is
   accurate, but `companion_rawi_id` is null in all 26,094 rows; the chain-derived
   `shawahid_companions` (38% resolved) is the usable table.
2. Dating mean abs error (35.5) is worse than the depth baseline (24.3), although the median is
   much better. The README reports only median / coverage / width, so the mean tail is not shown.
3. The README's "groups with a k=2 common link 0.368" uses all groups as denominator; among
   groups with ≥2 chains it is 0.896 (k3 0.375). "dated 0.368" equals the CL rate because every
   narrator has some interval, so it carries no information.
4. `edit_rates` row depth 0 has 157 edits, 0 transmissions and rate NA.
5. Spot-check 146425: `قالا` is not a join phrase, so a dual-joined segment stays unjoined.
6. `chains` and `groups` read slightly different cache snapshots (90,767 vs 92,225 pages).
